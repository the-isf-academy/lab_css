# lab_css

This directory contains HTML and CSS for a page for ELP.


## HTML
You can find the HTML for this page in the `index.html` file. You may need to edit this file in order to add more `div` structures or
to add classes or IDs to elements. It already links to the CSS file in this directory.

## CSS
You should write the CSS for this page in the `styles.css` file.

## Displaying the page
To display the page, you can open the HTML file in your web browser by using the command `open index.html` in your Terminal.
Once the page is open, you will need to refresh the page to see any edits you make to the files. You may need to do a "hard refresh"
of the page using `Cmd-Shift-R`.


✅ **You must implement `class` and `id` selectors**
- [ ][class selector example](https://developer.mozilla.org/en-US/docs/Web/CSS/Class_selectors#examples)
  - [ ] [id selector example](https://developer.mozilla.org/en-US/docs/Web/CSS/ID_selectors#examples)
- [ ] flexbox

🎨 **Go to [fonts.google.com](https://fonts.google.com/) to find a custom font.**
- Select `Get Font`
- Select `Get embeded code`
- Copy the code from the `Embed code in the <head> of your html` into the `head` of your `html` file
- You can then use the name of the font in the `css` file
