# Amusement
This directory contains HTML and CSS for a page advertising a Water World in Hong Kong.

## Context
This page should be designed to make people excited to go to water world and also to give them some information about what kind of
experience they can expect in the park.

## HTML
You can find the HTML for this page in the `index.html` file. You may need to edit this file in order to add more `div` structures or
to add classes or IDs to elements. It already links to the CSS file in this directory.

## CSS
You should write the CSS for this page in the `styles.css` file.

## Displaying the page
To display the page, you can open the HTML file in your web browser by using the command `open index.html` in your Terminal.
Once the page is opem, you will need to refresh the page to see any edits you make to the files. You may need to do a "hard refresh"
of the page using `Cmd-Shift-R`.
